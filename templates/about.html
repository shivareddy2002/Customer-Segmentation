About this Project

Amazon Customer
Segmentation

A production-grade unsupervised ML system that identifies distinct customer profiles from transactional data to power targeted marketing.

🎯 Problem Statement

  • Segment customers by purchasing behavior
  • Enable targeted marketing campaigns
  • Build personalized recommendation logic
  • Identify high-value vs. at-risk customers
  • Reduce churn through proactive strategy

✅ Project Objectives

  • Engineer RFM + behavioral features
  • Apply K-Means, Hierarchical & DBSCAN
  • Evaluate with silhouette score
  • Build visual insight dashboard
  • Deploy prediction for unseen customers

Algorithms

Three Clustering Approaches

01

K-Means Clustering

Primary algorithm. Optimal k selected via elbow method + silhouette scoring. Fast and scalable for production use.

02

Hierarchical Clustering

Ward linkage dendogram to understand nested cluster structure. Validates K-Means k choice visually.

03

DBSCAN

Density-based algorithm. Excellent for detecting noise and outlier customers who don't fit standard profiles.
